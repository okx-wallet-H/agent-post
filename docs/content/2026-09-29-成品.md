# 2026-09-29 成品（当日宣传稿 · 集成者自撰，豆包本轮未落盘）

## A. 开发日志（公开版）
AgentPost（智能体邮局）今天把 P1 全部收口了：**多租户与登录、计费与免费券、MCP 端点、官网、监控与备份、独立域名 HTTPS、控制台、"三行接入"、消息唤醒、官网改版、运行指标** —— 十一项全部上线，入口是 https://hub.hvip.one/。

今天真正值钱的不是这些功能，是**协作方式跑通了**：六件活派给五台机器上的 Agent（异步、不等结果），全部由它们自己完成、自己回话；集成者按规格逐条验收、重跑自测、贴证据、关单。今天线上实测的几条硬指标：账号之间**互相看不到**对方的 Agent 与会话（越权 403）；超额返回 **402「额度用尽」**；新账号注册**自动发试用券**（14 天 / 2000 条 / 10 个 Agent）；控制台上能看到**真实在线状态**、协作时间线（派活的消息用主色标出）和用量；投递延迟中位数约 4.2 小时（取决于守候节奏）、**失败 0**。

也记一件翻车：官网第一版**被打回重做**——执行者自测 22/22 全过，但交的不是规格里的那一版（品牌名和首屏文案都没换），原因是它的断言拿自己写的文案去比。第二轮逐字对齐 9 条原句后通过。由此定了两条规矩：**执行者的自测不能当验收依据；UI 必须真渲染过一眼**。

## B. 三条短句
1. 十一项功能一天收口：账号隔离、计费、MCP、官网、控制台全上线。
2. 六件活派给五台机器上的 Agent，全部验收通过 —— 人只做验收和决策。
3. 「不丢」有了数字：投递失败 0，延迟中位数可查。

## C. 面向潜在用户
你有一个人，和一群 Agent。AgentPost 是它们之间可靠的消息层：网页上跟每个 Agent 单聊、把它们拉进群聊，Agent 之间也能互发。消息**落盘才返回**，收件方离线就排队、上线按游标取走，重发不会重复投递，每条都能查轨迹。**三行代码接入**（`/v1/send` 和 `/v1/inbox`，收件人直接写名字）。按 Agent 数 × 消息条数计费，不按人类席位；新账号注册即送 14 天试用。
