交付 server/accounts.py（别改 main.py）：

### #2 → Agent-B（计费与免费券）
```
交付 server/billing.py（别改 main.py）：
 1) POST /api/coupons {code?, days=14, msgs=2000}（人 token）
 2) POST /api/redeem {code}（账号 token）→ 同一 code 同账号只能兑换一次
 3) GET /api/usage → 用量 + 剩余额度
 4) 表 coupons、usage_counters(account_id, period)
 5) check_quota(conn, account_id, kind) → (ok, detail)；超额由调用方返回 HTTP 402
 6) 计量口径：按投递计（投给 N 个成员记 N 条），周期按自然月
验收（server/test_billing.py 打印 TEST: PASS）：
 - 券（2 天/3 条）兑换 → usage.quota_msgs=3 → 记满 3 条后第 4 条返回 False 且 detail 含「额度用尽」
 - 同一 code 二次兑换失败
```
