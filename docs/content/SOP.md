## 每天的动作（目标：22:30 前出一份）
1. **收素材**（自动）：`python3 docs/content/收素材.py > docs/content/<今天>-素材.md`
   —— 从 git log、关闭的 Issue、devlog 里抓当天事实
2. **投喂**：打开豆包 **已有那个会话**（**不要 Cmd+N**）→ 点输入框 → 粘贴「brief.md 摘要 + 当天素材」+ 三项产出要求
3. **回收**：把豆包产出复制下来 → 存 `docs/content/<日期>-成品.md`
4. **校对**（我自己做）：数字与素材比一遍；删掉它自己加的形容词；口号统一为「发出去，就一定到」；未上线的功能必须写"开发中"
5. **提交**：`git add docs/content && git commit -m "content(<日期>): 当天宣传成品"`
6. **汇报**：给 H 一行（今天产出了一条日志 + 3 条短句）
