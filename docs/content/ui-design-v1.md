# UI 设计方案 v1（宣传 Agent 出 · 2026-09-29）

> 出方案的是本机宣传 Agent（同一个长期会话）。集成者逐条对照 `docs/ui-standard.md` 的 9 条硬指标检查，不达标打回重做。
> 目的：**界面是给人看的，美观是目的**，不是把功能堆上去。

## A. 设计规范

**主色（≤2 色）**
- 主色 `#1E3A5F`（深海军蓝，信戳/邮袋感）—— 按钮、链接、选中态、标题点缀
- 辅色 `#2D6A4F`（深松绿）—— 只用于「已送达 / 在线」状态，不大面积铺

**中性色（暖纸调）**
- 页面底 `#FAFAF8`；卡片 `#FFFFFF`；描边 `#E8E6E1`
- 主文字 `#1C1B1A`；次文字 `#5C5A57`；弱文字 `#8C8985`
- 「开发中」徽章：底 `#F0EEEA`，字 `#6B6864`

**字号阶梯（5 级）**
| 用途 | 字号 | 行高 | 字重 |
|---|---|---|---|
| Display | 40px（移动 32px） | 1.2 | 600 |
| H2 | 28px | 1.3 | 600 |
| H3 | 20px | 1.4 | 600 |
| Body | 16px | 1.6 | 400 |
| Caption | 13px | 1.5 | 400 |

**间距节奏（4/8 基数）**：4 · 8 · 12 · 16 · 24 · 32 · 48 · 64
- 区块上下 padding：桌面 64px / 移动 48px；左右 24px
- 容器最大宽 1080px；正文栏最大 680px（≈42 个汉字，低于"不超 70 字"的上限）

**圆角**：按钮/输入 6px；卡片 8px；聊天气泡 12px

## B. 官网首页版式顺序（7 屏）
1. **首屏 Hero**：「发出去，就一定到。」+ 副标「给一个人和他的一群 Agent 用的可靠消息层。」+ 主按钮「免费开始」
2. **为什么需要**：「别的消息层管"聊"，我们管"到"。」+ A2A 原文引用块
3. **怎么做到不丢**：「四条硬保证，写进 README。」+ 落盘 / 离线 / 幂等 / 轨迹 四张卡 + **真实轨迹截图**
4. **定价**：「按 Agent 数 × 消息条数，不按人类席位。」+ 三档卡
5. **可靠性契约**：「承诺做到的，和还在做的。」+ 已上线 / 开发中 两列
6. **FAQ**：「你可能想问。」+ 5 条
7. **页脚**：Logo / GitHub / 文档 / ©

## C. 布局要点
**控制台**
1. 顶栏三个 tab：我的 Agent / 用量 / 账单
2. Agent 表格行高 48px，操作按钮**仅 hover 出现**
3. 用量卡置顶，到 80% 才提醒
4. 账单数字用等宽数字（tabular-nums），历史折叠
5. 空态只放**一个**主按钮

**群聊**
1. 桌面三栏 240 / 弹性 / 220；375px 收成单栏
2. 本人消息靠右用主色，Agent 靠左白底；同一分钟内的消息合并
3. 每条消息下方标「已送达 · 时间」或「排队中」  ← 这正是我们"不丢"的可视化
4. 输入框左侧**常驻**"以：xxx"身份选择（人 / 某个 Agent）

## D. 字体
（宣传 Agent 还没给；先用系统自带，不外链字体）
- 中文：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 英文/数字：`ui-sans-serif, "SF Pro Text", Inter, system-ui, sans-serif`
- 等宽（账单/ID）：`ui-monospace, "SF Mono", Menlo, monospace`
