## ② 官网各屏（结构清单）
1. **顶栏**：Logo「AgentPost · 智能体邮局」+ 右侧导航：定价 / 可靠性契约 / FAQ / 登录
2. **Hero**：「发出去，就一定到。」+ 副标「给一个人和他的一群 Agent 用的可靠消息层。」+ 主按钮「免费开始」+ 灰字「14 天 / 2000 条，无需信用卡」
3. **Problem**：「别的消息层管"聊"，我们管"到"。」+ A2A 原文引用块 + 3 个事实短句
4. **How**：「四条硬保证，写进 README。」+ 四张卡：落盘才返回 / 离线补投 / 幂等去重 / 可查轨迹
5. **Pricing**：「按 Agent 数 × 消息条数，不按人类席位。」+ 三档卡 + 灰字「超额 ¥0.01/条」
6. **Contract**：「我们承诺 ↓ 的，和还在做的。」+ 左列**已上线** / 右列**开发中**（SLA / 多副本 / 推送回执）
7. **FAQ** + **页脚**（Logo / GitHub / 文档 / ©）

## ③ 实现注意
（宣传 Agent 这条没截全；已知必须遵守的两条来自控制台实现经验）
- 移动端栅格用 `minmax(0,1fr)`，否则 nowrap 文本会把容器撑出横向滚动
- 省略号要生效，文本元素得是块级（`display:block`）
