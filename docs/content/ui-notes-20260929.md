## 2. 每屏结构清单

### 官网首页
1. 顶栏：Logo AgentPost·智能体邮局 + 右列 定价/可靠性契约/FAQ/登录
2. Hero：「发出去，就一定到。」+ 副标「给一个人和他的一群 Agent 用的可靠消息层。」+ 按钮「免费开始」+ 灰字「14 天/2000 条，无需信用卡」
3. Problem：「别的消息层管"聊"，我们管"到"。」+ A2A 原文引用块 + 3 个事实短句
4. How：「四条硬保证，写进 README。」+ 4 卡（落盘才返回/离线补投/幂等去重/可查轨迹）
5. Pricing：「按 Agent 数 × 消息条数，不按人类席位。」+ 3 档卡 + 灰字「超额 ¥0.01/条」
6. Contract：「我们承诺做到的，和还在做的。」+ 左列已上线 / 右列开发中（SLA/多副本/推送回调）
7. FAQ：5 条 details 折叠
8. Footer：Logo + GitHub + 文档 + © 2026

### 控制台
1. 左侧栏 220px：Logo + 我的 Agent/用量/账单/设置 + 底部当前方案卡
2. 顶栏：标题 + 导出 + 「+ 新建 Agent」主按钮
3. KPI 三卡：本月消息（带进度条）/ Agent 数（在线·离线）/ 本月应付
4. Agent 表格：名称(首字母头像) / 状态点 / 本月消息 / 最后活跃 / 详情
5. 账单双卡：本期金额大数 + 明细行（标准方案 / 超额 / 合计）

### 群聊
1. 三栏 260 / 1fr / 240：会话列表 / 消息流 / 成员面板
2. 气泡：本人右主色，Agent 左白底；每条下方「已送达 · 时间」或「排队中 · Agent 离线」
3. 等待时一行淡灰斜体「等待 Agent 回复…」
4. 底部输入：左「以：我 ▾」身份选择器 + 输入框 + 发送
5. 成员每行：头像 + 名字 + 状态点 + 「以此身份发」按钮

## 3. 实现注意

1. 主区 grid 列用 `minmax(0,1fr)`，否则表格和消息流会撑破容器
2. 移动端 <860px：侧栏和成员面板 `display:none`，官网 nav 链接隐藏，全部单栏堆叠
3. SLA / 多副本 / 推送回调必须用「开发中」灰底徽章，不能写成已支持
