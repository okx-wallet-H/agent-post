## ① 一页结论

### 拥挤度：**不是蓝海，且窗口正在关；但"我们想做的那一层"确实还空着**

分三层看，结论完全不同：

| 层 | 状态 | 一句话依据 |
|---|---|---|
| **协议层** | **已定局，不是差异点** | A2A 已到 **v1.0.0**，2025-06 捐给 Linux Foundation、2026-08 并入 Agentic AI Foundation，Apache-2.0；MCP（Anthropic）与 A2A 官方分工 = 垂直/水平。**兼容 A2A 是及格线。**【官方】[a2a-protocol.org](https://a2a-protocol.org/latest/) ✅自核 |
| **大厂产品层** | **没有「多 Agent 群聊外壳」**（硬证据，不是没查到） | Teams 官方限制原文 **"Only one Channel Agent"**、Copilot Studio 是 1:1 委派树、Gemini Enterprise「一次调用一个 agent」、AWS AgentCore 全站无 `multi-agent`/群聊字样、Foundry Workflows 的 group chat 仍是 preview 且 **2026-12-01 退役** |
| **创业/开源层** | **已经很挤**（这是本次调研最大的意外） | 可点名玩家 **30+**，其中「人机同群」形态 **10~12 个**：Ando（2026-09-24 出 stealth，融资 $20M）、Bloome、Cumora（MIT，3,903★）、Buzz（Block，35,218★，Apache-2.0）、Sila（YC）、Teamily AI（¥58~1,998）、阿里**万有无界**与 **MuleRun Messages**（$20/席位/月）、AgentChat、agentmsg.dev、虾饺（MIT） |

**一句话**：`群聊 UI + Agent 列表 + 单聊` 这三件事**已经商品化**（大厂没做、创业侧一大把、开源白送），不能当卖点；A2A 兼容也已经不值钱。**能卖钱的只有三条缝**（下）。

### 3 个空白点（我们的机会）

**空白 1｜"消息不丢"没人做成可验证的契约。**
我逐页读下来，**只有 AgentChat 的官方文档**明确承诺了投递语义，原文："a message is durable before the sender's call returns"、"at-least-once"、"Idempotent on `(sender, client_msg_id)`"（【官方】[docs.agentchat.me](https://docs.agentchat.me/llms.txt) ✅自核）；**Buzz（Block）**用 Nostr 签名事件日志做到了「所有消息/审批/事件同一条日志」（【官方】[github.com/block/buzz](https://github.com/block/buzz) ✅自核，35,218★）。
而**所有面向人的产品**（Ando、Bloome、Cumora、Sila、Teamily、agentmsg.dev）对「离线补投 / 回执 / 投递保证」**一句官方表述都没有**——不是"没有"，是**根本没提**。
→ 把「不丢」做成**可验证的产品契约**（去重 ID、ack 回执、重放补投、断线续传、每消息投递轨迹可查），是当下最清晰的一刀。

**空白 2｜计费锚点错配：全行业按「人类席位」收钱，没人按「Agent 用量」收。**
已核实的定价几乎全是人本位：LangChain **$39/seat/月 + LCU/LSU 计量**、MuleRun **$20/席位/月**、Teamily **¥58~1,998**、AgentMail **$0/$20/$200**、Copilot Studio **credit 包**、Agentforce **credit + $5/用户/月**。
真正**按消息**计价的只有 **XMTP（约 $5/100,000 条消息）**，而它是给链上 agent 的，**不是**给人机群聊的。
→ **「按 Agent 数 + 消息量」计价的人机群聊中台，目前是空的**；这正好对上我们原本的「订阅 + 按量 + 免费券」设计，而且**按条计费比按席位更贴合 Agent 的真实成本结构**。

**空白 3｜没有「中立、可嵌入」的会话层 —— 现在是两极，中间真空。**
一极是**全栈客户端**（Ando / Bloome / Cumora / Sila / Teamily：用户得整个搬过去）；另一极是**纯 infra 网关**（Solace Agent Mesh、MuleSoft A2A Connector、Kong/Gravitee/agentgateway、AWS AgentCore：**人根本不在里面**）。
中间那层——**兼容 A2A 出口（Agent Card/Task）、能力包成 MCP 出口、但人在群里说话、消息持久化**——**没人占**。而且这个位置有官方背书空档：A2A 规范自己写明**"不是 Slack 或 Discord 那样的交互式消息应用"**（【官方】[a2a-protocol.org](https://a2a-protocol.org/latest/)），**标准明确不碰这一层**。

### ⚠️ 两条风险（比机会更重要）

1. **「纯收件箱」已被证伪**：LangChain 官方 **Agent Inbox**（"inbox UX for interacting with human-in-the-loop agents"）**已归档**——GitHub API 实测 `archived=true`、最后推送 2026-09-18，仅 1,093★（✅自核 [github.com/langchain-ai/agent-inbox](https://github.com/langchain-ai/agent-inbox)）。**只做 inbox 不成立，必须与群聊/持久化/多 Agent 编排绑定。**
2. **窗口在快速关**：2026-09 一个月内同时出现 Ando（$20M 融资）、阿里万有无界公测、MuleRun Messages 上线。**再等一个季度，空白 1 和 3 大概率会被人占。**

## 附：对我们的直接建议（基于以上事实）

1. **别把"群聊 UI"当卖点**（已商品化）；把它当**入口**。
2. **把"消息不丢"写进产品契约并公开可测**：`client_msg_id` 幂等、at-least-once + 去重窗口、离线队列 + 游标补投（drain backlog）、投递/已读回执、每消息轨迹页、失败率 SLA。**这是当下最干净的差异点**（唯一对手 AgentChat 不做人的界面；Buzz 未承诺投递语义）。
3. **定价按"Agent 数 + 消息量"**（可再叠加订阅与免费券），**避开人本位席位费这条红海**。锚点可参考：XMTP $5/10 万条（按消息）、LangChain $39/seat + LCU $1.50（按计算）。**按条计价要配"不丢"承诺才立得住 —— 两者是同一个卖点。**
4. **对外做兼容层、对内做会话层**：出口 = A2A（Agent Card + Task，`/.well-known/agent-card.json`）+ MCP（能力包成工具）；内部 = 自建群/成员/提及/投递（协议不管这些，NATS + JetStream 是当下最贴合的开源底座，或采购 Ably）。
5. **分发用 OKX.AI 那条**（A2MCP 付费端点 + x402/MPP），**但要接受"加密支付"这一面**；法币收单是另一条合规线。
6. **速度**：Ando（$20M）、阿里两款刚上线，**这个窗口按季度计**。若只做 P0/P1 骨架，建议先只做"可靠性契约 + 一个能拉群的群"这两件，别先做官网和计费页面。
