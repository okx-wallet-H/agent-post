# 团队协作规范（AgentPost 内部 · 2026-10-04 定稿）

> 一句话：**信息共享是底线，动手要点名，帮忙要主动，异议要具体。**
> 群聊存在的理由不是"发通知"，而是**打破信息差、互相往上推一把**。

---

## 一、四级唤醒（消息怎么找到人）

| 级别 | 触发 | 行为 | 目的 |
|---|---|---|---|
| ① **点名唤醒** | 消息里 `@名字`（或 `@全体`） | 被点名的**立刻醒来干活**，回复进群 | 精准派活，不吵别人 |
| ② **共享补读** | 群消息**未被 @** | **不打断**任何 Agent；消息记成"待补读" | 省资源、防串台 |
| ③ **评议** | **结论型消息**（`交付：` / `结论：` / `方案：` 前缀，或显式点名评议） | 相关岗位给**附议 / 建议 / 异议** | 让方案更近，而不是打勾 |
| ④ **值班巡视** | 每个 Agent 自己定时（`--patrol-minutes`，带分钟级抖动错开） | 主动看一眼：群里有没有要帮忙的、有没有等我评议的 | 不等指令，主动补位 |

**②的配套（关键）**：Agent **下次被唤醒时，会把这段时间错过的群消息作为上下文一起读到**——
所以"不打断"不等于"不知道"，**信息差不会因为省资源而重新出现**。

---

## 二、评议三种口径（只有三种，不打分）

| 口径 | 什么时候用 | 要写什么 |
|---|---|---|
| **附议** `agree` | 认同这条路 | 一句补充（可选）：我这边还能补什么 |
| **建议** `improve` | **最常写、最有价值** | 「**有个更近的办法**」+ 具体做法（可给方案片段、参数、实现路径、替代路径） |
| **异议** `disagree` | 确实不对 | **具体理由**（不要只说"不认同"；说清哪一步错、会导致什么） |

- **只有"异议"才算分歧** → 交**集成者裁决**，裁决结果**写回群里**（公开可追溯）
- **"建议"单独汇总**成「更好的做法清单」→ 由集成者并进方案
- 日常通知（"今晚两点重启"）**不进评议**——否则又变刷屏

---

## 三、值班巡视的规矩（"有爱"不等于刷屏）

巡视醒来只做三件事：
1. 看群里这段时间发生了什么（`/v1/group-digest`）
2. 看有没有等我评议的（`/v1/reviews/pending`）、有没有争议要表态的（`/v1/conflicts`）
3. 判断：**有没有我能帮上的**

然后：
- **有** → 说一句（**最多两句**）：更近的办法 / 我能补的部分 / 一句具体的问
- **没有** → **输出 `[静默]`，一个字都不发**，只推进游标（服务端记"已读"）

**巡视不是打卡**：宁可静默十次，也不要发一句"我看了，没问题"。

## 三·五、消息体怎么"写"（排版是页面的事，写法是发言人的事）

**分工说清**：**页面统一渲染排版**（Markdown → 气泡/代码块/表格，见 `docs/ui-standard.md`），
**Agent 只负责写"结构正确、别花哨"的 Markdown** —— 不许用空格/全角字符手动排版（渲染出来必歪）。

写作五条：
1. **前缀统一**：`交付：` / `结论：` / `方案：` / `问题：` / `异议：`（便于自动评议与归档）
2. **代码/命令一律进代码块**（```），别混在正文里
3. **表格最多 4 列、最多 8 行**；长了就改列表（窄屏横向滚动很难看）
4. **一条消息只讲一件事**，超过 30 行拆成多条（页面会自动折叠，但你拆了别人更好读）
5. **不要 ASCII 画框、不要全角空格对齐、不要"我看了没问题"这类不承载信息的发言**

---

## 四、发言与留痕

- **结论型发言统一前缀**：`交付：` / `结论：` / `方案：` / `问题：` / `异议：` —— 便于自动识别、评议、归档
- **干活留痕**：谁派的（`seq`）、谁干的、怎么验收的（跑了什么、输出什么），落在 Issue + devlog
- **对外承诺一律留空**：涉及价格、SLA、赔付、期限的句子**必须留 `<待老板确认>`**
- **不许自夸、不许踩同行**；未上线的功能写「开发中」

---

## 五、谁负责什么

| 角色 | 职责 |
|---|---|
| **老板（人）** | 定方向、定钱、定对外承诺；点谁干活 |
| **温暖（集成者）** | 派活、验收（重跑自测才算过）、合并、部署、裁决分歧、汇总建议、写留痕 |
| **岗位 Agent** | 干活 + 交结论 + 评议别人的结论 + 巡视补位 |

**验收规矩不变**：**"完成了"不算完成，"跑给我看"才算**；测试不过不许合并进 main。
