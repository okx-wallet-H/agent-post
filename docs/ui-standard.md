# 官网 UI 标准（不达标就打回重做）

## 什么时候进入 UI 打磨
**触发条件**：P1 的功能闭环完成 —— 多租户隔离、计费与免费券、MCP 端点、监控备份**四项都验收通过**。
（在那之前只保证"能用"，不上打磨；否则改一版废一版。）

## 谁来设计
本机**宣传 Agent**（豆包，同一个长期会话）出设计方向与文案排版；集成者实现到 `site/index.html` 并截图验收。

## 质感硬指标（逐条打勾，任何一条不满足就打回）
1. **不土**：一套主色（≤2 色 + 中性灰）、一套字号阶梯（≤5 级）、一套圆角与间距节奏
2. **留白**：段与段之间不挤；正文行宽不超过约 70 个汉字宽
3. **首屏 3 秒说明白**：一句话定位 + 一句副标 + 一个按钮，别的都不放
4. **真实**：不放抽象渐变插图；要么用**真实产品截图**，要么不放图
5. **不吹**：未上线功能必须标「开发中」；不出现"最强/第一/颠覆"
6. **动效克制**：只允许 hover / 轻微淡入；不加自动轮播
7. **移动端**：375px 宽度下不横向滚动、不挤行
8. **加载**：单文件、无外部 CDN；首屏 < 100KB
9. **可读**：正文对比度足够；链接有下划线或明显颜色

## 打回流程
1. 集成者按上面 9 条逐条检查 → 出一条具体问题清单（带截图）
2. 把问题清单发给宣传 Agent 重做
3. 重做后重新逐条过；连续两轮不过就回到"参考竞品首页"重新定方向
