# #38 摸排报告：币安「带单交易员」数据接口能取多少

**结论先行**：官方 API **没有**公开的带单员榜单/数据接口（只有带单员本人管理端点）；网页版榜单走的是**非官方 bapi 接口，参数名未公开、大概率需要登录态**；官方条款**明令禁止抓取**，有封号先例。此路数据可得性低、合规风险高。

## 1) 官方 API：只有「带单员本人」管理端点，无公开榜单

- `GET /sapi/v1/copy-trading/futures/userStatus`（TRADE，需签名）：查**自己**是不是带单员，返回 `data.isLeadTrader` 布尔。
- `GET /sapi/v1/copy-trading/futures/leadSymbol`（USER_DATA，需签名）：查**自己**带单白名单币种。
- 文档：developers.binance.com 的 Future Copy Trading 目录；OpenAPI：github api-evangelist/binance 的 binance-copy-trading-api-openapi.yml。
- 官方社区（dev.binance.vision，2023-11）员工原话：Copy Trading feature is not available via API（带单员列表、收益率、跟随人数等**不提供**）；2024-06-06 更新日志加的也只是上面两个本人端点。**「带单员排行榜」官方接口至今不存在（未验证是否有后续更新，按最近文档判断）。**

## 2) 非官方网页接口（实测两次）

- 旧合约榜单 `https://fapi.binance.com/fapi/leaderboard/topParticipants?period=7d&symbol=BTCUSDT`：实测 **HTTP 404**（币安错误页）——已下线/迁移。
- 网页端 `https://www.binance.com/bapi/futures/v1/friendly/future/copy-trade/home-page/query-list`：实测**存在**（无参与 `pageNumber=1&pageSize=10` 均返回 `{"code":"000002","message":"illegal parameter"}`）——**参数名未公开，形状未验证**；参考同类开源项目（apollotoday/Binance-copy-trading-bot）用网页抓取且 **cookie 每 2-3 天要刷新** → 判定：**大概率需要登录态/Cookie**。按纪律停止深入。
- 单次返回条数 / 翻页方式 / 总量上限：**未验证**（接口没摸到真响应，不编）。

## 3) 字段（仅「合约榜单」口径的第三方逆向，带单榜字段未验证）

Go 库 bfldb（rtunazzz/bfldb）逆向的 leaderboard 字段：`encryptedUid`、`nickname`、`followerCount`、`followingCount`、`userPhotoUrl`、`twitterUrl`、`introduction`、持仓流 `otherPositionRetList`（ticker/entryPrice/amount/时间戳）。注意这是**合约 leaderboard**，不是带单榜，两者字段是否一致未验证。带单员典型字段（收益率/回撤/跟随人数/AUM/历史曲线/当前带单币种）**官方无公开来源**。

## 4) 限速与风控

- 官方带单 API：20 req/10s（文档明示）；榜单类无官方限速口径。
- 非官方接口：无公开口径；Apify 第三方方案默认要代理（暗示直连易封）；**未做批量验证（纪律禁止）**。

## 5) 合规边界（照实写）

Binance Terms of Use / Prohibited Use Policy（2026-01-05 版）明文禁止：爬虫/机器人/脚本/自动化方式访问或复制服务、绕过导航结构或安全措施、伪造请求头、规避 robot 协议、对基础设施施加不合理负载。违反后果：**暂停/终止服务 + 法律行动**。先例：2025-10 币安以「使用未经授权第三方工具」封停 600+ 账户并永久拉黑、没收收益。**结论：抓取带单榜数据直接踩官方红线，不建议做。**
